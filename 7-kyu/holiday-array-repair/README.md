<h2><a href=https://www.codewars.com/kata/5579906f2f0c0d0766000127/train/javascript target="_blank">Holiday Array Repair</a></h2><h3>7 kyu</h3><h3 id="the-problem">The Problem</h3><p>Your colleague has been working on a program that returns the number of days of holiday that people in your coding company can take in the remainder of the year. </p><p>His program outputs the number of holidays each employee has left as an integer within an array. However, the program is not working properly. Alongside the element that specifies the number of holidays are several other useless elements. These other elements are of a variety of data types and none are integers.</p><p>Your colleague boasts that he has more days of holiday left than you.</p><h3 id="your-task">Your Task</h3><p>You are given two arrays, <code>a1</code> (your colleague's) and <code>a2</code> (yours), which contains at most one integer: the number of days of holiday that person has left.</p><p>If your colleague is telling the truth, the function should return the string <code>"Right"</code>. If your colleague is wrong, the function should return the string <code>"Wrong"</code>. If you both have the same number of days of holiday, the function should return the string <code>"Same"</code>. If your colleague's program is beyond repair and does not produce an integer in either arrays, the function should return a string <code>"Not possible"</code>.</p>
