<h2><a href=https://www.codewars.com/kata/590fd3220f05b4f1ad00007c/train/javascript target="_blank">Simple Fun #253: Cool String</a></h2><h3>7 kyu</h3><h1 id="task">Task</h1><p>Let's call a string cool if it is formed only by Latin letters and no two lowercase and no two uppercase letters are in adjacent positions. Given a string, check if it is cool.</p><h1 id="inputoutput">Input/Output</h1><p><code>[input]</code> string <code>s</code></p><p>A string that contains uppercase letters, lowercase letters numbers and spaces.</p><p><code>1 ≤ s.length ≤ 20.</code></p><p><code>[output]</code> a boolean value</p><p><code>true</code> if <code>s</code> is cool, <code>false</code> otherwise.</p><h1 id="example">Example</h1><p>For <code>s = "aQwFdA"</code>, the output should be <code>true</code></p><p>For <code>s = "aBC"</code>, the output should be <code>false</code>;</p><p>For <code>s = "AaA"</code>, the output should be <code>true</code>;</p><p>For <code>s = "q q"</code>, the output should be <code>false</code>.</p>
