<h2><a href=https://www.codewars.com/kata/52ed326b8df6540e06000029/train/javascript target="_blank">Simple elevator</a></h2><h3>7 kyu</h3><p>There is a house with 4 levels.In that house there is an elevator.You can program this elevator to go up or down,depending on what button the user touches inside the elevator.</p><p>Valid levels must be only these numbers: <code>0,1,2,3</code></p><p>Valid buttons must be only these strings: <code>'0','1','2','3'</code> </p><p>Possible return values are these numbers: <code>-3,-2,-1,0,1,2,3</code></p><p>If the elevator is on the ground floor(0th level) and the user touches button '2'the elevator must go 2 levels up,so our function must return 2.</p><p>If the elevator is on the 3rd leveland the user touches button '0'the elevator must go 3 levels down, so our function must return -3.</p><p>If the elevator is on the 2nd level,and the user touches button '2'the elevator must remain on the same level,so we return 0.</p><p>We cannot endanger the lives of our passengers, so if we get erronous inputs, our elevator must remain on the same level.So for example:</p><ul><li><code>goto(2,'4')</code> must return 0, because there is no button '4' in the elevator.</li><li><code>goto(4,'0')</code> must return 0, because there is no level 4.</li><li><code>goto(3,undefined)</code> must return 0.</li><li><code>goto(undefined,'2')</code> must return 0.</li><li><code>goto([],'2')</code> must return 0 because the type of the input level is array instead of a number.</li><li><code>goto(3,{})</code> must return 0 because the type of the input button is object instead of a string.</li></ul>
