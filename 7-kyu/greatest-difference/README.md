<h2><a href=https://www.codewars.com/kata/56b12e3ad2387de332000041/train/javascript target="_blank">Greatest Difference</a></h2><h3>7 kyu</h3><p><strong>Task:</strong> Find the number couple with the greatest difference from a list of number-couples.</p><p><strong>Input:</strong> A list of number-couples, where each couple is represented as a string containing two positive integers separated by a hyphen ("-").</p><p><strong>Output:</strong> The number couple with the greatest difference, or <code>False</code> if there is no difference among any of the couples or in case of an empty list.</p><p><strong>Additional Information:</strong></p><ul><li>All number couples will be given as strings.</li><li>All numbers in the couples are positive integers.</li><li>If multiple couples have the same greatest difference, return the first one encountered in the input list.</li><li>If there is no difference (both numbers in a couple are equal), return <code>False</code>.</li></ul>
