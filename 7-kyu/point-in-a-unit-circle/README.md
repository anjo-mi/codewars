<h2><a href=https://www.codewars.com/kata/58da7ae9b340a2440500009c/train/typescript target="_blank">Point in a unit circle</a></h2><h3>7 kyu</h3><h1 id="task">Task</h1><p>Write a function that returns <code>true</code> if a given point <code>(x,y)</code> is inside of a unit circle (that is, a "normal" circle with a radius of one) centered at the origin <code>(0,0)</code> and returns <code>false</code> if the point is outside.</p><h1 id="input">Input</h1><ul><li><code>x</code>: The first coordinate of the given point.</li><li><code>y</code>: The second coordinate of the given point.</li></ul><h1 id="notes">Notes</h1><ul><li>The region bounded by the circle is considered to be an <code>open disk</code>, so points on the boundary of the circle should return <code>false</code>.</li><li>We are using the euclidean metric.</li></ul>
