<h2><a href=https://www.codewars.com/kata/5a40fc7ce1ce0e34440000a3/train/javascript target="_blank">Numbers with d occurrences of digit d</a></h2><h3>7 kyu</h3><p>In this kata, we want to discover a small property of integers.</p><p>We say that an integer is a <strong>dd</strong> number if it contains <code>d</code> occurrences of a digit <code>d</code>, (<code>d</code> is in <code>[1,9]</code>).</p><h2 id="examples">Examples</h2><ul><li><code>664444309</code> is a <strong>dd</strong> number, as it contains <code>4</code> occurrences of the digit <code>4</code></li><li><code>30313</code>, <code>122</code> are <strong>dd</strong> numbers as they respectively contain <code>3</code> occurrences of the digit <code>3</code>, <code>1</code> occurrence of the digit <code>1</code>, <code>2 </code> occurrences of the digit <code>2</code></li><li><code>123109</code>, <code>0</code>, <code>56542</code> are not <strong>dd</strong> numbers</li></ul><h2 id="task">Task</h2><p>Your task is to implement a function that takes a <strong>positive</strong> integer (type depends on the language) and returns a boolean corresponding to whether the integer is a <strong>dd</strong> number or not.</p>
