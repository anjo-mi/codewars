<h2><a href=https://www.codewars.com/kata/560fbc2d636966b21e00009e/train/javascript target="_blank">Map function  issue</a></h2><h3>7 kyu</h3><p>In computer science, a programming language is said to have first-class functions if it treats functions as first-class citizens. Specifically, this means the language supports passing functions as arguments to other functions, returning them as the values from other functions, and assigning them to variables or storing them in data structures.</p><p>First-class functions are a necessity for the functional programming style, in which the use of higher-order functions is a standard practice. A simple example of a higher-ordered function is the map function, which takes, as its arguments, a function and a list, and returns the list formed by applying the function to each member of the list. For a language to support map, it must support passing a function as an argument. See more on <a href="https://en.wikipedia.org/wiki/First-class_function" data-turbolinks="false" target="_blank">https://en.wikipedia.org/wiki/First-class_function</a></p><p>Your task is to rewrite your own <code>map</code> function which takes :</p><ul><li>an array </li><li>a predicate function <code>func</code> which returns true (boolean) with even arguments</li></ul><p>For example :</p><pre><code>map([1,2,3,4],func)produces[ false, true, false, true ]  </code></pre><p>The code also has to perform input validation, return  :</p><ul><li>'given argument is not a function' if <code>func</code> is not a function</li><li>'array should contain only numbers' if any elements are not numbers</li></ul>
