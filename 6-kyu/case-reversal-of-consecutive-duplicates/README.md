<h2><a href=https://www.codewars.com/kata/577c2d68311a24132a0002a5/train/javascript target="_blank">Case Reversal of Consecutive Duplicates</a></h2><h3>6 kyu</h3><p>The aim of this Kata is to write a function which will reverse the case of all consecutive duplicate letters in a string.  That is, any letters that occur one after the other and are identical.</p><p>If the duplicate letters are lowercase then they must be set to uppercase, and if they are uppercase then they need to be changed to lowercase. </p><p><strong>Examples:</strong></p><pre><code class="language-javascript"><span class="cm-string">"puzzles"</span> <span class="cm-operator">--&gt;</span> <span class="cm-string">"puZZles"</span><span class="cm-string">"massive"</span> <span class="cm-operator">--&gt;</span> <span class="cm-string">"maSSive"</span><span class="cm-string">"LITTLE"</span>  <span class="cm-operator">--&gt;</span> <span class="cm-string">"LIttLE"</span><span class="cm-string">"shhh"</span>    <span class="cm-operator">--&gt;</span> <span class="cm-string">"sHHH"</span></code></pre><p>Arguments passed will include only alphabetical letters <code>A–Z</code> or <code>a–z</code>.</p>
